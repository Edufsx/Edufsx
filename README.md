# (EN 🇺🇸) 🧙🏼 Eduardo Ferreira da Silva
`Data Scientist`

📚 My name is Eduardo Ferreira da Silva. I hold a Teaching Degree in Mathematics from the Federal Institute of Education, Science and Technology of São Paulo (IFSP) and a Technical degree in Electronics from the same institution. During these two programs, I built a solid foundation in Mathematics, Statistics, and Programming Logic.

🏹 Currently, I have been studying and developing projects in the field of Data Science, integrating my academic background with technological knowledge. I mainly use Python, SQL, and Machine Learning to solve problems and generate value through data.

📈 In each of my repositories, I aim to highlight the process of data extraction, manipulation, and transformation in order to support data-driven decision making, perform predictions about events of interest, and solve problems through logical, analytical, and critical reasoning.

## 🏗️ Projects

Check out some of my projects:

- 🏎️ [f1-lakehouse-and-champion-prediction](https://github.com/edufsx/f1-lakehouse-and-champion-prediction): End-to-end data platform combining Lakehouse architecture and Machine Learning to predict Formula 1 champions;

- 🛒 [customer-loyalty-predict](https://github.com/Edufsx/customer-loyalty-predict): Machine Learning pipeline for customer loyalty prediction, from feature engineering to API deployment;

- 📈 [covid-19-data-processing-and-rk4-numerical-simulations](https://github.com/Edufsx/covid-19-data-processing-and-rk4-numerical-simulations): COVID-19 data analysis and numerical simulations using the Runge-Kutta (RK4) method.

# (PT 🇧🇷)🧙🏼 Eduardo Ferreira da Silva
`Cientista de Dados`

📚 Meu nome é Eduardo Ferreira da Silva, sou licenciado em Matemática pelo Instituto Federal de Educação, Ciência e Tecnologia de São Paulo (IFSP) e Técnico em Eletrônica pela mesma instituição. Durante essas duas formações construí uma base sólida em Matemática, Estatística e Lógica de Programação.

🏹 Atualmente, tenho estudado e desenvolvido projetos na área de Ciência de Dados, integrando minha base acadêmica com conhecimentos em tecnologia. Utilizo, principalmente, Python, SQL e Machine Learning para resolver problemas e agregar valor através dos dados. 

📈 Em cada um dos repositórios busco evidenciar o processo de extração, manipulação e transformação de dados para tomada de decisões embasadas, realização de predições sobre eventos de interesse e resolução de problemas por meio de um raciocínio lógico, analítico e crítico. 

## 🏗️ Projetos

Confira alguns dos meus projetos:
- 🏎️ [f1-lakehouse-and-champion-prediction](https://github.com/edufsx/f1-lakehouse-and-champion-prediction): Plataforma de dados end-to-end com arquitetura Lakehouse e Machine Learning para predição de campeões da Fórmula 1;

- 🛒 [customer-loyalty-predict](https://github.com/Edufsx/customer-loyalty-predict): Pipeline de Machine Learning para predição de fidelidade de clientes, da engenharia de features até o deploy via API;
